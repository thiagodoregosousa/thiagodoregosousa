## About

I work on statistics for time series, stochastic processes and indirect inference, with a focus on simulation-based estimation of stochastic volatility models. I also have a background in cryptography, mainly lattice-based and post-quantum schemes.

I believe in open source: I publish my research code and enjoy contributing to other people's projects.

## Code

All repositories: [github.com/thiagodoregosousa](https://github.com/thiagodoregosousa)

**R packages (on CRAN)**

- [**GEVStableGarch**](https://CRAN.R-project.org/package=GEVStableGarch) — ARMA-GARCH and ARMA-APARCH models with stable, GEV and GAt innovations: estimation, simulation, forecasting and Value-at-Risk. [docs](https://thiagodoregosousa.github.io/GEVStableGarch/) · [source](https://github.com/thiagodoregosousa/GEVStableGarch)
- [**bgev**](https://CRAN.R-project.org/package=bgev) — bimodal GEV distribution: density, distribution function, quantiles, random variates and MLE. [docs](https://thiagodoregosousa.github.io/bgev/) · [source](https://github.com/thiagodoregosousa/bgev)
- [**mbev**](https://github.com/thiagodoregosousa/mbev) — multimodal bivariate extreme value (MBEV) distribution (R).
- [**cran_journey**](https://github.com/thiagodoregosousa/cran_journey) — a guide to making your first R package and getting it onto CRAN.

**SageMath code for cryptography papers**

- [**matrix-ntru**](https://github.com/thiagodoregosousa/matrix-ntru) — matrix NTRU (Nayak et al., 2008) and its LLL attack (do Rego Sousa and Carneiro, 2024).
- [**ETRU**](https://github.com/thiagodoregosousa/ETRU) — the ETRU cryptosystem (Jarvis and Nevins, 2015) and May's dimension-reduction idea for the LLL attack.
- [**integral_domain_matrix_ntru**](https://github.com/thiagodoregosousa/integral_domain_matrix_ntru) — matrix NTRU over an integral domain (Wijayanti et al., 2023).
